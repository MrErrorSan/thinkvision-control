## ThinkVision Control 0.1.0 (preview)

The first release that controls every display attached to your PC, not only the ThinkVision P32p-20, and the first one in five languages.

### New
- **Several displays.** Pick a display at the top of the window, or choose **All together** to move them with one set of sliders. Each display keeps its own offset, so their brightness stays matched.
- **Other monitors.** The P32p-20 stays fully supported. Other Lenovo monitors, and any monitor that speaks the DDC/CI standard, now work too, marked **Experimental**. Experimental displays always ask before switching input. **Copy capability report** helps get a monitor fully supported.
- **Laptop screens.** A laptop's built-in screen gets a brightness slider (Windows and Linux).
- **Languages.** English, Español, 简体中文, Français and Deutsch. The app follows your system language, or pick one in **Settings → Language**. The other translations are new; corrections are welcome.
- **On Linux, setup happens inside the app.** Cards for monitor access, the i2c-dev module, the GNOME tray extension, KDE's PowerDevil, NVIDIA and laptop brightness each have a button. It asks for your password once through the system prompt, then the app checks the result itself. Packages install through apt, dnf, zypper, pacman, xbps or apk.
- **A scriptable command line.**
  - `--display <name|id|all>`, `--input 1|2|3`, `--version` and `--yes`.
  - A JSON array when you target several displays.
  - On Windows, use `tvc` (installed next to the app) in scripts to get the output and exit codes.

### Changed
- **Bad arguments fail.** They exit with code 2 and a short message instead of opening the window.
- **`--input` on the command line needs `--yes`.** `thinkvision://input/...` links and the hotkeys still switch a verified display directly.
- **The tray is as before.** The icon shows the app is running in the background, so your shortcuts work; click it to open the window.
- **Your 0.0.8 settings carry over by themselves.** The old file is kept as `settings-0.0.8.json`.

### Fixed
More than 80 issues from a full review of 0.0.8. Among them:
- **Running `--get` while the app was open** no longer makes the app forget a crash; the next start no longer misses safe mode.
- **With automatic Day/Night on,** a command-line change is no longer undone right away, and `--get` no longer writes to the monitor.
- **The Monitor tab** keeps your keyboard focus and open menus while values change.
- **Restoring a backup** no longer switches the input, and restores colour mode first.
- **Monitors whose capability list has nested values** (e.g. the P40w-20) are no longer reported as not responding.
- **Most controls now work from the keyboard and with a screen reader.**
- **Linux:** clippy-clean builds, safer single-instance handling, and right-sized permission and setup hints.

### Good to know
- **This is a preview.** The new Linux and macOS code paths have been reviewed and compile-checked, but not yet tried on real hardware. On Windows it was tested live on a P32p-20.
- **Downloads:** `ThinkVisionControl-Setup-0.1.0.exe` (Windows) and `thinkvision-control-0.1.0-linux-x64.tar.gz` (Linux). Checksums are in `SHA256SUMS.txt`.
