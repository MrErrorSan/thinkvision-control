**Verdicts:**
- **C** (confirmed): reproduced by a test or a live run, or the exact lines were read.
- **P** (partial): the issue is real, but the audit overstated its scope or trigger.
- **R** (refuted): the claim was wrong. Refuted claims are listed at the end.
- **L** (latent): the code is wrong, but it can't be reached with the P32p-20-only build. It becomes reachable with multi-display or experimental support.

**Severity:** H, M or L. **Task** names the plan task that fixes the issue.

The first audit's line numbers are wrong in 9 files: link.rs, mccs.rs, cli.rs, crash.rs, fake.rs, packet.rs, linux/i2c.rs, macos/link.rs and macos/locator.rs. The behaviour it describes is right. Use the verification reports for line numbers.

**Corrections from the reproduction pass:**
- **CORE-06 is P, not C.** After a corrupt cache, the resident app does recover with one live read 2 s after connecting. It never recovers in CLI runs or in safe mode.
- **CORE-07 is P.** The normal path reads live capabilities first. Synthesized capabilities authorise writes only in safe mode or with a corrupt or foreign cache, and that case was reproduced.
- **CORE-10's** trigger "the newest drag value fails evaluate" can't happen. The missing-EndDrag path is real.
- **CORE-03:** wrong error positions are worse than cosmetic. They count from the innermost value list (P40w-20: 14 reported, 363 actual).
- **Full table:** [verify-core-a.md](verification/verify-core-a.md), 34 claims: 24 confirmed, 8 partial, none refuted. Raw output: [verify-run.txt](verification/verify-run.txt).

## Speculative (checked, not confirmed; watched during verification)

- **Inno Setup version.** `WizardStyle=modern dynamic` may need Inno 6.6 rather than 6.5. The CI install pins nothing.
- **macOS install over a running app.** `ditto` over a running app bundle.
- **Two processes doing DDC at once on Windows.** Closed by APP-03 if `--get` forwards to the resident copy.
- **Intel rotation hotkeys.** Intel graphics hotkeys (Ctrl+Alt+arrows) on some machines.
- **False permission hint on Linux.** The setup hint may blame permissions when the monitor is simply missing.

## Refuted or corrected claims from the first audit

- "A duplicated `60(...)` containing FF is rejected": **refuted.** It is accepted, and last wins (CORE-02).
- "mccs.rs may already have input names": **refuted.** There is no table (APP-19).
- "The macOS backend reads the serial": **refuted.** There are no serial or EDID bindings (ffi.rs:36-38).
- "Concurrent dxva2 calls on different handles are safe": **unverified**, and still an assumption (see the plan's risks).
- The A9 "silent fallback" and A13 "combo shows Off" claims only happen in rarer paths than stated (both P).
- "Engine panic → `Status{NotResponding}`" is impossible in release builds: `panic = "abort"`.
